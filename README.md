This repository contains the implementation of various numerical methods and celestial mechanics models to simulate the Earth's orbit around the Sun, determine the apparent position of the Sun from a specific location (Cardedeu, Catalonia), and estimate the electrical energy generated by a residential photovoltaic installation.

The main objective is to solve Newton's Law of Universal Gravitation using Ordinary Differential Equations (ODEs), apply coordinate system transformations, and model solar irradiance to evaluate the energy yield of photovoltaic panels throughout the year.

## Repository Contents

The project is structured into Python modules, each handling a specific stage of the simulation and analysis pipeline:

| File | Description |
| :--- | :--- |
| `trajectoria.py` | Simulation of the Earth's orbital trajectory around the Sun solving gravitational ODEs. |
| `posiciosolcardedeu.py` | Calculation of the Sun's apparent position and trajectory in the local sky (azimuth and elevation) for Cardedeu. |
| `energiagenerada.py` | Computation and modeling of solar irradiance and photovoltaic electrical energy production. |
| `comparativa_metodes.py` | Numerical comparison and error analysis between different ODE integration schemes (Euler, Runge-Kutta). |
| `func_canvibase.py` | Auxiliary library containing coordinate change functions (heliocentric, geocentric, local horizon system, etc.). |
| `figures/` | Folder where automatically generated plots, orbits, and energy curves are saved. |
| `Pràctica 2.pdf` | Theoretical documentation, mathematical formulation, and full project report. |
